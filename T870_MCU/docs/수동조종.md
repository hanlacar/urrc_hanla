# T870 수동 조종 (WASD)

브릿지가 떠 있으면 키보드로 차를 움직일 수 있다.
manual 소스는 모드·우선순위와 무관하게 최우선이라 언제든 개입된다.

---

## 준비 (최초 1회)

```bash
mkdir -p ~/t870_tools
```
```bash
cp -f ~/Downloads/drive_wasd_v1_0826.py ~/t870_tools/
```

워크스페이스가 없으면 먼저:
```bash
cd ~ && tar xzf ~/Downloads/t870_mcu_v8_0826.tar.gz
```
```bash
cd <워크스페이스> && colcon build --symlink-install && source install/setup.bash
```

---

## 실행

### 0. 포트 확인 — 매번

USB 꽂는 순서에 따라 포트 번호가 바뀐다.
GPS 와 아두이노가 자리를 바꿔 앉아 반나절 날린 적이 있다.

```bash
python3 ~/t870_tools/check_ports_v1_0826.py
```

★ 표시가 아두이노다. 아래 명령의 포트를 그 값으로 쓴다.

### 1. 브릿지 (터미널 1, 계속 켜둠)

```bash
sudo chmod 666 /dev/t870_mcu
```
```bash
cd <워크스페이스> && source install/setup.bash
```
```bash
ros2 launch t870_mcu t870_mcu.launch.py port:=/dev/t870_mcu
```

`시리얼 준비 완료` 가 뜰 때까지 기다린다.

> 켜는 순간 조향이 0도로 한 번 움직인다. 차량 주변을 확인하고 기동할 것.

### 2. 조종 (터미널 2)

```bash
source <워크스페이스>/install/setup.bash
```
```bash
python3 ~/t870_tools/drive_wasd_v1_0826.py
```

## 키

```
  W   전진 (누를 때마다 단계 올림: 정지 → 1 → 2 → 3)
  S   후진 (한 번 더 누르면 정지)
  A   조향 좌 3도
  D   조향 우 3도
  C   조향 중앙

  Space  정지
  F      급정거 (램프를 건너뛴다)
  E      E-Stop 토글
  R      E-Stop 래치 해제

  1 2 3  전진 단계 직접
  0      정지

  Z   구간 측정 시작
  X   구간 측정 끝 (결과 출력)
  Q   종료
```

속도: 1단 0.229 m/s · 2단 0.526 m/s · 3단 약 0.82 m/s

---

## 첫 조작 전 확인

```
□ 앞 5m 공간 확보 (또는 바퀴 띄우기)
□ E-Stop 담당 1명, 다른 작업 금지
□ 차량 반경 5m 사람 없음
□ 첫 주행은 반드시 1단
□ 경사면 금지 (브레이크 없음)
```

## 자주 겪는 문제

| 증상 | 조치 |
|---|---|
| `Package 't870_mcu' not found` | `source <워크스페이스>/install/setup.bash` |
| `serial unavailable` 반복 | 포트 번호 확인. `check_ports` 실행 |
| `Device or resource busy` | `sudo fuser -k /dev/t870_mcu` |
| `Permission denied` | `sudo chmod 666 /dev/t870_mcu` |
| 텔레메트리 두절 / 엔코더 `----` | 포트가 아두이노가 아닐 가능성. `check_ports` |
| `ESTOP` 이 안 풀림 | `R` 을 누른다 |
| 차가 0.5초마다 섰다 감 | 이 도구는 10Hz 로 계속 보내므로 정상은 아님. 브릿지 로그 확인 |
| 키가 안 먹음 | 이 창을 클릭해 포커스를 준다 |

## 구간 측정 (counts_per_meter)

```
1. C          조향 중앙
2. 출발선에 뒷바퀴 축 정렬
3. Z          시작 표시
4. W          주행
5. 도착선에서 Space, 완전히 멈출 때까지 기다린다
6. X          끝 표시
```

3회 반복하고 `Q` 로 나가면 평균이 출력된다.

거리가 10m 가 아니면:
```bash
python3 ~/t870_tools/drive_wasd_v1_0826.py --distance 5
```

**현재 확정값: counts_per_meter = 533.1  (1카운트 = 1.9mm)**

## 알아둘 것

- 이 도구는 브릿지를 거친다. `measure.py` 와 **동시 실행 불가** (시리얼 포트 단일 점유).
- `Q` 나 창 닫기, Ctrl-C 어느 쪽이든 정지 명령을 보내고 종료한다.
- 끄기 전에 `C` 로 조향을 중앙에 두고 끌 것.
  조향은 시간 기반이라 전원을 끌 때의 위치가 다음 부팅 때 "중앙" 이 된다.
