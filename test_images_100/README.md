# Selected 100 training-set images for regression testing

These images were part of training and are not an independent generalization test set.
Images and labels are symbolic links to the original 0811 dataset.

Selection balances rare labels, brightness, contrast, saturation, edges, temporal spacing, and visual diversity.

Class image counts: road=100, W_line=3, Y_line=97, R_light=11, Y_light=4, G_light=6, Left=0, etc_light=5, stop=36, traffic20=0, C_line=33, words=70
